# NASA Mission Planner 🚀

## Project Idea

NASA Mission Planner is a simple webpage that displays information about NASA space missions. It is designed as an educational tool to make learning about space missions simple and organized.

## Technologies

* HTML
* CSS
* JavaScript
* GitHub

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. The NASA Mission Planner webpage will open.
