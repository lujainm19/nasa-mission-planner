# Reflection

## What I Learned

I learned how to use GitHub to organize and manage a project: I did that by creating issues, with labels. I also created 2 branches, made commits, and used pull requests to merge the changes I made in the branches into the main branch.

## What Was Challenging or Fun

Something I found challenging and had never tried before was understanding how branches and pull requests work through GitHub directly. I liked it because I could see clearly how each change could be tracked through commits.

## What I Would Improve

If I had more time, I would improve the design of the website and add more NASA missions and information. I would also add more interactive features to make the project more useful.
